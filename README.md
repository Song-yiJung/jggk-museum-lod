# 조선총독부박물관 문서 서지 목록

국립중앙박물관 「조선총독부박물관 문서」 상세페이지를 수집하여 정리한 서지 목록과
수집 스크립트.

## 규모

문서철 602 · 문건 6,568 · 문서 41,913 · 총 116,983면
수집 시점 2025년 11월

## 파일

- `조선총독부박물관문서_수집_전체목록(v.251220).csv` — 서지 목록
- `조선총독부박물관문서_웹스크래핑.ipynb` — 수집 스크립트 (Google Colab)

## 배경

국립중앙박물관은 공공데이터포털에 문권정보 592건을 공개하고 있다.
문서철 단위 목록이며 하위 문건·문서 정보는 제공되지 않는다.
이 저장소는 그 문권 체계를 기반으로 상세페이지를 수집하여
하위 계층의 서지를 문서종류·쪽수와 함께 정리한 것이다.

## 한계

- 상세페이지에 공개된 범위만 수집한다.
- 「권」·「문건」은 breadcrumb 문자열을 분리한 결과이며, 소장기관의 공식 계층
  구분과 일치하는지는 별도 확인이 필요하다.
- 쪽수는 상세페이지 표기값이며 실제 이미지 수와 다를 수 있다.

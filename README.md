# 조선총독부박물관 문서 서지 목록

국립중앙박물관이 공개하는 「조선총독부박물관 문서」 상세페이지를 수집하여 정리한
서지 목록과 수집 스크립트.

`jggk` = 朝鮮總督府博物館 (조선총독부박물관)

---

## 배경

국립중앙박물관은 공공데이터포털에 「조선총독부박물관 문권정보」 592건을 공개하고 있다.
문권제목·정리분류·연도 세 항목으로 구성된 **문서철 단위** 목록이며, 연도는 일부만
기재되어 있고 문서철 아래의 문건·문서 정보는 제공되지 않는다.

이 저장소는 그 문권 체계를 기반으로 박물관 웹 상세페이지를 수집하여
하위 계층의 서지를 문서종류·쪽수와 함께 정리한 것이다.

## 코드

`code/scrape.py` · `code/scrape.ipynb`

Google Colab에서 실행한 수집 스크립트.

```
STEP 1   대분류별 권 목록 수집
STEP 2   pseq ID 탐색
STEP 3   유효 ID 대상 상세페이지 전수 요청
STEP 4   문서 상세 + 문건 메타 병합
STEP 5   pseq별 breadcrumb 수집 (캐시 방식)
```

**수집 실적** 6,568 페이지 · 소요 35분 41초 · 평균 3.07 req/s · 실패 0

`code/postprocess.py` — breadcrumb을 권·문건으로 분리하고 파일 식별자를 매핑하는
후처리 스크립트. *(작성 예정)*

## 한계

- **공개 범위에 한정된다.** 상세페이지에 게시되지 않은 문서는 포함되지 않는다.
  실물 문서철에 존재하나 디지털화되지 않은 것이 있을 수 있다.
- **「권」·「문건」은 breadcrumb 문자열을 분리한 결과**이며, 소장기관의 공식 계층
  구분과 일치하는지는 별도 확인이 필요하다.
- **쪽수는 상세페이지 표기값**이다. 펼침 촬영이나 동일 낱장의 반복 촬영으로 인해
  실제 이미지 수와 다를 수 있다.
- **수집 일자가 특정되지 않는다.** 스크립트 최종 저장은 2025년 11월 23일이며
  실행은 그 이전이나 정확한 일자는 확인되지 않는다. 웹 자료는 시점에 따라
  내용이 달라질 수 있으므로 재현 시 이 점을 고려할 것.
- 포털 공개 592건 중 538건이 수집분과 명칭이 일치한다. 나머지는 도면·지도
  대분류의 계층 상이, 연도 표기 차이, 포털 미공개 등에서 발생한다.
